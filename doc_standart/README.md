# Стандарт архитектуры: оплата и доставка

Это **учебное пособие**: как система *должна* быть устроена в этом проекте (Laravel 10, e-commerce).

Текущая реализация («как есть») описана отдельно: [../doc/README.md](../doc/README.md).  
Этот каталог — целевая модель. Её используют для ревью, онбординга и проектирования новых провайдеров.

## Как читать

1. Сначала [00-principles.md](00-principles.md) — правила, которые нельзя нарушать.
2. Затем предметные главы. В каждой: **цель → контракт → диаграмма → пример → антипаттерн из текущей реализации**.
3. Не копируйте фрагменты «как есть» в новый код, если в главе они помечены как антипаттерн.
